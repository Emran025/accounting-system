# حزمة تصميم منصة المنتجات والعروض

هذه الحزمة هي خط أساس شلالي قبل تنفيذ أي نموذج أو API أو شاشة مرتبطة بالمنصة العامة للمنتجات والعروض.

| الوثيقة | الغرض | حالة الاعتماد |
|---|---|---|
| [01_Marketplace_Architecture_and_Integration_Design.md](./01_Marketplace_Architecture_and_Integration_Design.md) | نطاق المنصة، تجربة الاستخدام، ملكية البيانات، سياسة العروض والوسائط، مواضع التنفيذ، الأمان، وخطة الشلال. | مسودة — تتطلب اعتماد A-01 إلى A-06. |
| [02_Marketplace_Contract_OpenAPI.yaml](./02_Marketplace_Contract_OpenAPI.yaml) | عقد HTTP المقترح بين Accore والمنصة المركزية: الترويسات، الأحداث، اللقطات، الوسائط، الأخطاء، وعدم التكرار. | مسودة — تتطلب مراجعة الطرفين والأمن. |
| [03_Requirements_Traceability_and_Approval_Matrix.md](./03_Requirements_Traceability_and_Approval_Matrix.md) | تتبع المتطلبات إلى البيانات والمكونات والعقد والاختبارات وملاك الاعتماد. | مسودة — تستخدم كقائمة بوابة قبل البناء. |

> لا يُنفّذ أي مسار أو ترحيل قاعدة بيانات أو نشر خارجي قبل اعتماد نهج التزامن، وسياسة الوسائط، وصلاحيات النشر، ومجال الإصدار الأول.

## قاعدة مصدر الحقيقة

- تعد هذه الحزمة المرجع المؤقت داخل `accore-erp` لأنها تصف بيانات المؤسسة المصدرة.
- بعد الاعتماد، تنسخ النسخة الموقعة من العقد إلى `accsystem_operational` في مسار عقود مشترك، ويمنع تعديل جانب واحد من دون رفع نسخة العقد والتوافق عليها.
- لا يعد سجل `ProductSite` في المستودع المركزي بديلاً عن الكتالوج أو العرض؛ يستخدم فقط لتعريف المنتجات البرمجية للنظام البيئي.
